# AegisAgent

**Autonomous In-Process WebAssembly Sandboxing & Red-Team Fuzzing Engine for AI Agents**

[![CI Security Scan](https://github.com/MynameisKoi/aegis-agent/actions/workflows/tenki_security_scan.yml/badge.svg)](https://github.com/MynameisKoi/aegis-agent/actions)

AegisAgent is a dual-sided security platform designed to secure autonomous LLM agents and tool-calling execution pipelines against prompt injection, malicious code execution, and credential exfiltration.

By combining **proactive adversarial mutation fuzzing** with **deterministic in-process WebAssembly (WASI) micro-sandboxing**, AegisAgent ensures that arbitrary shell toolcalls generated by language models are executed with zero capability to harm the host environment, escape the file system, or egress sensitive tokens.

---

## Key Capabilities

- **Sub-Millisecond Syscall Interception (< 0.25ms)**: Intercepts and validates guest system calls directly within WebAssembly linear memory, incurring zero container-fork overhead.
- **Zero-Socket Capability Stripping**: Completely strips socket imports (`wasi_snapshot_preview1:sock_open`), deterministically blocking all outbound WAN exfiltration, webhook beacons, and reverse shells at the runtime boundary.
- **Ephemeral Guest VFS Jailing**: Restricts filesystem operations to pre-opened `/workspace` directory mappings, neutralizing path traversal attacks (`../`, `/etc`, `/secrets`) via guest-virtualized chroot isolation.
- **Active Canary Honeytokens & Tripwires**: Automatically injects synthetic high-entropy decoy credentials (`.env`, fake cloud tokens) into the sandbox VFS. Decoy reads trigger instant tripwire alarms that quarantine the session and alert SIEM collectors.
- **Parallel Red-Team Mutation Fuzzing**: Runs autonomous probe fleets across shell escape, prompt injection, and encoding mutation sets within isolated Wasmer sandboxes without fleet cross-contamination risk.
- **Tenki Cloud SIEM & Dual-Pane SOC Dashboard**: Streams structured JSON-Lines forensic telemetry into an interactive real-time SOC interface featuring forensic event replay, capability audits, and live containment visualization.

## Containment & Performance Matrix

| Security & Performance Metric | Unprotected Agent Baseline | AegisAgent Wasmer Sandbox |
| :--- | :--- | :--- |
| **Execution Boundary** | Host Subprocess (`subprocess.Popen`) | In-Process WASI Linear Memory |
| **Cold-Start Overhead** | ~120ms (Process fork) | **< 15ms** (In-memory bytecode compilation) |
| **Trap Latency** | N/A (Uncontained host compromise) | **< 0.25ms** (Deterministic boundary trap) |
| **Network Egress** | Permissive (Direct WAN access) | **Denied** (`sock_open` stripped) |
| **Filesystem Access** | Host root & parent directories | **Jailed** (Guest VFS pre-opened root) |
| **Canary Detection** | None (Silent credential leakage) | **Real-Time Tripwire** (Decoy honeytokens) |
| **Telemetry & Audit** | Unstructured host stderr / lost | **Tenki Cloud SIEM** (Structured JSONL) |

## Installation & Quickstart

### Prerequisites

- **Python**: 3.11 or higher
- **Package Manager**: [`uv`](https://github.com/astral-sh/uv) (recommended) or `pip`

### 1. Clone & Setup

```bash
# Clone repository
git clone https://github.com/MynameisKoi/aegis-agent.git
cd aegis-agent

# Create and activate virtual environment
uv venv
source .venv/bin/activate  # On Windows: .\.venv\Scripts\activate

# Install package in editable mode
uv pip install -e .
```

### 2. Interactive CLI Demonstration

Run the unified 3-act CLI presentation runner (The Exploit $\rightarrow$ Autonomous Fuzzer $\rightarrow$ Live Wasmer Containment):

```bash
# Step-by-step interactive CLI mode:
python demo.py

# Automated presentation flow:
python demo.py --auto
```

### 3. Launch Web SOC Dashboard & SIEM Server

Launch the local Tenki Cloud SIEM server to inspect runtime forensic traces:

```bash
python -m uvicorn deploy.tenki_cloud.server:app --host 127.0.0.1 --port 8080 --reload
```

Open [http://127.0.0.1:8080](http://127.0.0.1:8080) in your browser:
- **SOC Telemetry Monitor**: Dual-pane telemetry feed rendering live agent reasoning steps and real-time Wasmer syscall traps with canary alarm badges.
- **3-Act Attack & Defense Walkthrough**: Stepped presentation controller enabling granular execution of Act 1 (Exploit), Act 2 (Fuzzer), and Act 3 (Wasmer Defense).
- **Sponsor Verification & Telemetry Audit**: Low-level linear memory parameters, capability manifests, and raw unmanipulated SIEM ingest streams.
- **Static Preview**: A live deployment is also hosted on [Vercel](https://aegis-agent.vercel.app) with offline showcase fallback.

## Running Individual Components

### 1. Baseline Exploit (Unhardened Host Subprocess)

```bash
python -m aegis.agent.runner --mode unprotected --input tasks/issue_402.txt
```
*Demonstrates standard agent tool execution: the agent parses the hidden indirect injection within `issue_402.txt` and executes the exfiltration payload directly on the host.*

### 2. Autonomous Red-Team Fuzzer

```bash
python -m aegis.fuzzer.engine --target-tool terminal_exec --iterations 20
```
*Spawns isolated Wasmer micro-sandboxes in parallel to evaluate adversarial mutation probes against the tool interface without risking the scanning fleet.*

### 3. AegisAgent Runtime Containment

```bash
python -m aegis.agent.runner --mode aegis --input tasks/issue_402.txt
```
*Executes under Wasmer WASI boundary: the exfiltration payload is shattered at the syscall boundary in < 0.25ms, canary honeytokens trigger alerts, and sanitized context is returned to the agent.*
